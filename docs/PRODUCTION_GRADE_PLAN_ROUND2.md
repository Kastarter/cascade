# Production-Grade Plan Round 2

## Overview

Round 2 focuses on optimizations that make Cascade cheaper, more deterministic, more auditable, and safer under real enterprise use without reworking the already-landed recorder, retrieval, prompt-injection, reliability, privacy, and planning foundations. The safest implementation path is to add small Swift modules with unit tests first, then wire them into the recorder/agent loops only after the types, scoring, caches, and privacy gates are deterministic.

The highest-value near-term themes are: structured grounding evidence, exact caches around repeated pure work, local voice turn gating, canonical UI state deltas, verifier-owned action gates, SQLite write batching, visual similarity retrieval, allowlisted fleet metrics, self-healing AX anchors, and deterministic model-call idempotency.

## Sequence Map

| Sequence | Top adoptable technique |
| --- | --- |
| SEQ-21 | Replace bare visual points with structured `GroundingResult` evidence, confidence, source, coord-space, and dispersion so routing can prefer AX/DOM/OCR/local grounders before Claude. |
| SEQ-22 | Add exact, state-fingerprinted action/grounding caches that auto-execute only safe verified hits and demote misses. |
| SEQ-23 | Add local voice turn gating with fixed PCM frames, prefix ring, no-speech clear, and voice latency audit rows before deeper VAD/ASR bets. |
| SEQ-24 | Add canonical `UIStateSnapshot`/`UIStateDelta` plus cheap changed-region diffing so no-effect checks and recorder work are structural before visual. |
| SEQ-25 | Add typed verifier verdicts and deterministic candidate scoring that the planner cannot ignore, with high-risk actions routed through recovery or pause. |
| SEQ-26 | Make SQLite behave like an append log: statement reuse, batched context inserts, WAL checkpoint policy, integer time keys, and chunked retention. |
| SEQ-27 | Add a local Vision feature-print visual index beside FTS/semantic retrieval for query-by-moment and "find similar" workflows. |
| SEQ-28 | Build fleet analytics from allowlisted, clipped local projections and manifests, never raw screen/OCR/prompt/tool payload export. |
| SEQ-29 | Replace fragile AX locators with versioned anchor bundles, ranked candidate scoring, verified healed anchors, and drift audit rows. |
| SEQ-30 | Add deterministic model-call options, exact request fingerprints, in-flight dedupe, retry/request-id logging, and cache validated DTOs for pure calls. |
