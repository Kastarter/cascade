## AREA 1 — Where to search (typed SourceRouter + stateful evidence)

**Root bugs:** two disconnected routing systems; `isSearchShapedGoal` (brittle boolean) over/under-matches; **`hasEvidence` treats any non-empty tool text as evidence** (a "no results" string counts as success → agent stops searching).

**Approach:** one typed routing layer in ProviderKit consumed by chat, assist, record Q&A, and CU. `SourceIntent` distinguishes locate_visible / answer_record / find_file / web_fact / instructional_with_record_dependency / action / mixed / ambiguous / no_search. `SourcePlan` = ordered sources + cleanQuery + reason + requiredSource + escalation + stop policy. Evidence is **stateful**: not_checked / checked_no_evidence / checked_supported / checked_insufficient / unavailable / refused. Route every ask before answering.

**Changes:**
- **NEW `Sources/ProviderKit/SourceRouting.swift`** — `SourceIntent`, `SourceID`, `SourceCard`, `SourcePlan`, `EvidenceState`, `SourceEvidence`, `SourceAvailability`, `SourceRouter`, `SourceCardRegistry`. Cards (onScreen / recordedMemory / localFiles / web / action): scope, freshness, privacy, cost, tool names, evidence semantics, failure modes, pos/neg examples. (ProviderKit is imported by CU, RecordRecall, RecordSearchAnswerer, SandboxKit, AgentOrchestrator, AppShell.)
- **`Sources/SandboxKit/AgentTaskPlanner.swift`** — replace the planner-owned `routeSearch` (~L356) with a thin wrapper around `SourceRouter`; move/typealias `SearchRoutingIntent`/`SearchResource`/`SearchRouteHint` (~L108-197) to the ProviderKit types; expand `parseSearchRoute`/`searchRouteRequestBody` to parse reason/requiredSource/stopPolicy/escalationPolicy, preserving current JSON fields for cache/test compat.
- **`Sources/ProviderKit/RecordRecall.swift`** — keep the text tool API; add structured companion (`performEvidence(_:) -> SourceEvidence` or `ToolResultStatusEnvelope.parse`). No-match envelope (~L279) → `checked_no_evidence`; hits → `checked_supported` with cited `[#id]`.
- **`Sources/ProviderKit/AgentHarness.swift`** — structured evidence for search_files/list_folder/read_file (~L248-271): no mdfind hits → `checked_no_evidence`; privacy refusal → `refused`; paths → `checked_supported`. (Fixes the hasEvidence bug at the source.)
- **`Sources/ProviderKit/ComputerUseAgent.swift`** — replace `resourceCatalogNote` (~L721-733) with `SourceCardRegistry.renderCatalog(harnessTier:recallEnabled:includeWeb:)`; same registry feeds CU / Scout / planner / RecordSearchAnswerer.
- **`Sources/ProviderKit/RecordSearchAnswerer.swift`** — SourcePlan-aware; instructional (~L151-153) becomes `instructional_with_record_dependency` only when it needs the user's past/screen record (don't force generic how-to through record recall).
- **`Sources/AgentOrchestrator/AgentOrchestrator.swift`** — `askRecord` (~L262) accepts `sourcePlan: SourcePlan? = nil`; if focus nil and plan lacks recordedMemory, return source-mismatch instead of silently record-first; pass cleanQuery/reason into RecordSearchAnswerer.
- **`Sources/AppShell/CascadeAppModel.swift`** — (a) chat shortcut (~L966-989): `SourceRouter.route(...)` first, dispatch by plan (onScreen→showOnScreen; recordedMemory→askRecord; localFiles→harness; web→bg web or explicit web-unavailable; mixed→ordered). (b) replace `isSearchShapedGoal` (~L4263) with pure `routeIntentHeuristic(_:) -> SourcePlan` fallback. (c) `SearchEvidenceBundle` (~L2577-2604) → `SourceEvidenceBundle` keyed by SourceID; `hasEvidence` true only for `.checked_supported`. (d) `collectCheapLocalEvidence`/`judgeSearchEvidence` (~L4584-4638) → `collectEvidence(for:)`/`reviewEvidence(plan:evidence:)` consuming states. (e) assist planning (~L2096-2200): SourcePlan per non-action subtask; skip CU if plan answers it; pause if web required + bg-web unavailable. (f) `source.route` + `source.evidence` audit rows (hashes/counts only, like `assistSearchUngatedAuditDetail` ~L4290-4305).
- Tests: `AgentTaskPlannerTests` (intent→plan cases), `CascadeAppModelTests` (typed intent, no-result≠evidence, selectedMoment forces record), `RecordRecallTests` + `AgentHarnessTests` (evidence states).

## AREA 2 — Smarter agents (bounded ContextPack + fix bg Claude fallback)

**Root bug:** `BackgroundWebAgent.episodeOnce` (Claude fallback) constructs `ComputerUseAgent` with only `WebHarness.toolDefinitions()` + a provider that only runs `WebHarness.run` — the injected local harness/recall tools from `configuredBackgroundWebAgent` are **silently unavailable on the Claude path** (Scout gets them). Also context drifts across 3 ad-hoc note builders.

**Approach:** one bounded `AgentContextPack` (budgeted, deterministic, hash-deduped) fed into on-screen Opus, Scout, and background planning/turns. First concrete fix = compose a combined harness provider so Claude fallback reaches both WebHarness + injected tools. Proactive set-of-marks affordances instead of relying on the model to call read_page/list_interactives.

**Changes:**
- **NEW `Sources/ProviderKit/AgentContextPack.swift`** — pure `AgentContextPack`/`AgentContextSection`/`AgentAffordanceMark`: deterministic order, per-section + total char budgets, dedupe body by hash, privacy-safe audit descriptor (names/chars/hashes/freshness). Dependency-light (AppShell + SandboxKit, no package cycle).
- **`Sources/SandboxKit/BackgroundWebAgent.swift`** — (a) fix Claude-fallback harness in `episodeOnce`: `combinedHarnessProvider` (WebHarness tool names → WebHarness+audit; else injected `harnessProvider`+`sandbox.harness`); construct CU with `harnessTier: injected==nil ? .off : harnessTier`, `harnessProvider: combined`, `extraTools: WebHarness.toolDefinitions()`, `recallEnabled: injected != nil && recallEnabled`, `includeStructuredRecallContent`, `resourceCatalogEnabled: true`. (b) add `planningContextProvider: (@MainActor (String) async -> String?)?` + cached `jobContext`; call before planning, audit `sandbox.context.inject`, pass into `planner.plan(..., conversationContext:)` + `replan`. (c) rename `scoutWebContext` → neutral `webAffordanceContext`, inject into BOTH Scout + Claude paths (proactive `PAGE NOW` / `CLICKABLE / FILLABLE NOW`).
- **`Sources/SandboxKit/WebHarness.swift`** — `minimizedInteractives` ranking by task-relevant tokens + role priority + label length + DOM order (not first-N-per-role); stable marks `A1 [button] Search -> click_text text="Search"`; validation still on exact safe labels.
- **`Sources/AppShell/CascadeAppModel.swift`** — (a) replace ad-hoc arrays in `initialAssistNote`/`initialScoutNote`/`episodeNote` with `contextPack(goal:surface:nudge:affordanceMode:)` (preserve sources: contextMemo, groundingNote/scoutContextNote, autoRecallInitialNote, planningPriorNote, trajectorySketchNote, failureMemoryNote); `context_pack.inject` audit. (b) `configuredBackgroundWebAgent`: set `runtime.planningContextProvider` building the same pack. (c) `scoutSkillPush` → compact frontmost skill summary (name/useWhen/caveats), pull recipes via use_skill. (d) reflection helper: on terminal/repeated failures save redacted `AgentFailureMemory`; `reflection.inject` audit.
- Tests: `AgentContextPackTests` (order/budget/dedupe/audit), `BackgroundWebAgentTests` (provider availability→.off, injected enables tiers+recall), `WebHarnessTests` (relevance ranking, poisoned labels suppressed), `AgentExperienceIntegrationTests` (reflection selected+audited, no raw text).

## AREA 3 — WasteDetector + agent creation (dataflow-across-surfaces + synthesize/validate)

**Root bug (your crypto miss):** `dataflowParameters(in:)` compares only `appName`/`bundleIdentifier`, so copy Google→Notion **inside Safari** (same app) is never a dataflow → `candidateCount=0`. Also: parameterized mining bypasses literal mining; token-only clustering; param grouping merges positions by value-hash; agent creation = blind `upsertAgent` with no synthesis/validation; proposals cleared before creation succeeds.

**Approach:** Stage 1 harden discovery (literal + parameterized complementary; TraceProfile clustering; resolved surface/document identity into recipe steps; copy/paste as live-value dataflow slots). Stage 2 harden creation (synthesize→validate→audit→persist). Keep `appName` for macOS activation; use `surface`/document identity for workflow identity + signatures + replay.

**Changes:**
- **`Sources/WasteDetection/WasteDetector.swift`** — (a) `useParameterizedMining=true` must NOT bypass literal mining; add `detectReport(...)` returning raw/episode/literal/parameterized/mined/final counts (`detect` = `.results`); require support evidence before promotion, literal fallback if parameterized empty. (b) `TraceProfile` per candidate (action shape, surface flow, bundle flow, hashed document identity from window title, target identities, copy/paste edges, param roles, duration bucket, occurrence IDs); replace token-only single-link merge with profile-compatible clustering; versioned signature `routine:v2:<profileHash>|<tokens>`. (c) `dataflowParameters(in:)` takes the surface/document resolver from `makeWaste`; copy→paste is a dataflow edge when source/dest differ by **surface or document hash** even if native app/bundle identical; mark paste `isParameter=true`, set `sourceStepIDs`, key `paste:<destField>:from:<sourceField>`. (d) `abstractParameterSummary` group by category + event-index role + target/source/dest field identity + edge identity (value hashes = evidence only).
- **`Sources/WasteDetection/TypedActionAbstractor.swift`** — `TypedAction`/`TypedActionEpisodeClusterer` gain non-PII profile fields (normalized target key, resolved surface, doc hash bucket, data-slot role); use in clustering similarity (don't collapse same-shape on different web apps/fields).
- **`Sources/CascadeMemory/CascadeMemory.swift`** — `RecipeStep` optional `surface: String?`, `documentIdentityHash: String?`, `dataflowEdgeID: String?` (nil default for old recipes); populate from `makeWaste`; `RecipeActionIdentity.key(for:)` uses `surface ?? appName` + doc/param metadata (leave appName for activation).
- **NEW `Sources/CascadeMemory/WebAppIdentity.swift`** — privacy-safe `from(windowTitle:)` doc identity: strip browser chrome, normalize, `AuditIdentity.hash(...)`; fold in URL host/path later without changing callers.
- **`Sources/AgentOrchestrator/AgentOrchestrator.swift`** — `createAgent(from:)` from direct `upsertAgent` → synthesize+validate+persist: `AgentPlanSynthesizer`/`AgentPlanValidator` build a live-value-aware plan from goal/recipe/trace/occurrence IDs; validate anchors/targets/surface flow/dataflow edges/held-out occurrences; audit `agent.synthesis.validated|failed`; throw before upsert on failure.
- **`Sources/AgentOrchestrator/WorkflowCurator.swift`** — curator prompt includes live-value slots + dataflow edge summaries (goal says "paste current copied price into Notion", not "cmd-v recorded clipboard"); pass keys/kinds/labels/shapes/hashes, no raw values.
- **`Sources/AppShell/CascadeAppModel.swift`** — (a) refresh audit: `parameterizedMiningAuditDetail` → report with separated raw/episode/literal/parameterized/mined/reviewable/curated/managerPending counts + hashed signatures (so `candidateCount=0` reveals which stage dropped it). (b) `recipeStepNeedsLiveValue` = `isParameter && (kind == .type || isPasteShortcut(step) || !sourceStepIDs.isEmpty)`. (c) `approveCurated`/`createTaughtAgent`: call `createAgent(from:)` first, clear proposal/teachPreview only on success.
- Tests: `ParameterizedWorkflowMiningTests` (same-browser Google→Notion cross-surface dataflow; paste=live param w/ sourceStepIDs; no raw leaks; same-shape different-webapp ≠ same signature), `PrefixSpanMinerTests`, `ParameterizedMiningIntegrationTests` (separated counts; literal fallback), `CascadeAppModelTests` (recipeStepNeedsLiveValue; approve doesn't clear on throw), `AgentOrchestratorTests` (validate-before-persist; refuse invalid), `AgentStoreTests` (RecipeStep round-trip; identity differs by surface).

5. **Recipe schema:** `RecipeStep.surface/documentIdentityHash/dataflowEdgeID` + `RecipeActionIdentity` + `WebAppIdentity.swift`.
6. **WasteDetector discovery:** literal+parameterized complementary; TraceProfile; cross-surface copy/paste; slot/edge grouping; report counts.

**Dependencies:** routing infra before chat/assist/CU wiring; evidence wrappers before evidence review; `SourceCardRegistry` before ContextPack + CU prompts; RecipeStep schema before WasteDetector metadata; agent synthesis after WasteDetector trace profiles.
